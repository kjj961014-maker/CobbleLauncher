What we are building

Cobble Launcher is an independent hobby project for a private Minecraft server community. Its initial target is Immersive Cobblemon 6.2.0 on Minecraft 1.21.1, NeoForge 21.1.252, and Java 21.

The goal is to reduce manual setup errors and help friends keep matching modpack versions when playing together.

Planned player experience

  • Sign in with a Microsoft account that owns Minecraft Java Edition.
  • Install the required game runtime and permitted modpack files.
  • Receive signed updates and server announcements.
  • Adjust memory settings and launch the shared modpack.

CurseForge integration

The proposed integration uses the official CurseForge API to look up project and file metadata and download files where third-party distribution is permitted. Mod authors' distribution choices must be respected.

Developer API access and an approved approach for end-user downloads are still being arranged. This page does not claim CurseForge approval.

Current development status

A Windows installer and launcher implementation have been built locally. Installation of the base game, Java, and NeoForge has been tested, alongside automated authentication, download, update, and UI checks.

Live Microsoft login, the complete modpack download, a full game launch, and connection to the intended server still require end-to-end verification. The development build is not presented as a finished public release.

Project and distribution

The project is intended for personal, non-commercial use. The launcher's own source is licensed under MIT. Minecraft, the modpack, individual mods, shaders, and other game assets remain subject to their respective licenses and permissions; they are not bundled in the launcher installer.
